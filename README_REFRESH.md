## 💼 Projetos em destaque

### ✅ [TaskFlow Dark Pro](https://github.com/jrmateusalmeida/taskflow) — Projeto público

Aplicação **full-stack de gerenciamento de tarefas e projetos**, desenvolvida para praticar integração entre interface web, API REST, autenticação e banco de dados.

**Principais funcionalidades:**
- Dashboard com indicadores de tarefas e progresso.
- Quadro Kanban com organização por status.
- Cadastro e acompanhamento de projetos.
- Calendário de tarefas e prazos.
- Relatórios por status e projeto.
- Cadastro, login e autenticação com JWT.

**Stack:** React · TypeScript · Tailwind CSS · Java · Spring Boot · PostgreSQL

📸 [Veja o código, as capturas de tela e a documentação no repositório.](https://github.com/jrmateusalmeida/taskflow)
